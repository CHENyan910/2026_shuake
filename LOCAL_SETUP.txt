新版网站本机使用说明（2026-10-16）

项目来源：https://github.com/qiu-changhao/auto_expriment
课程地址：https://sysaq.ustc.edu.cn/lab-study-front/examTask/22

使用步骤
1. 双击 start.cmd，选择 1，在 Chrome 中自行完成学校账号登录。
2. 选择 5 可检查网站适配及全部未学课程，不会开始学习。
3. 选择 3 开始学习。程序自动从任务表格点击“去学习”，按网站时长逐项处理。
4. 选择 2 可导出全部课程名称及 course_list.json；这一步是可选的，不再需要手动翻页。
5. 选择 6 可验证约 20 秒的真实课程计时及保存。

题库与模拟考试（2026-10-19）
重新双击 start.cmd 打开更新后的菜单；已有旧菜单窗口需要先关闭。
1. 选择 1，确认项目浏览器已登录并打开当前任务。
2. 选择 10“自动模拟考试”：自动进入模拟、排队、答题、核对保存、等到允许交卷后提交并查询成绩。
   已有未完成模拟时继续原试卷；没有未完成模拟时会开始一次新的模拟。
3. 只查看之前的模拟成绩，选择 11，不会开始新考试。
4. 选择 8 整理全部题库，选择 9 更新可搜索的题库复习文件和 CSV。
题库已经整理完成，无须每次重复整理。模拟期间请保留浏览器和程序窗口。
模拟考试入口只处理模拟试卷。
正式考试：按本次已明确授权，选择菜单12会自动确认已核对的安全承诺，并完成排队、进入试卷和答题。
正式考试每题保存成功后等待15秒再答下一题；100道题仅题间等待合计24分45秒，另需加载保存时间。
已有未完成正式试卷时继续原试卷；没有未完成记录时会开始一次新的正式考试。
菜单12通过网站正常控件确认承诺；承诺条款变化或要求扫码、手写签名时会保留页面并停止。
请关闭旧菜单后重新双击 start.cmd，以显示更新后的选项12。

课程要求与进度
程序分别读取网站的“必学时长”和“选学时长”，两项都达标才报告完成。
本次检查任务 22 显示必学 04:32:00、选学 01:28:00；实际运行始终以当前页面为准。
config.json 的 required_hours 为此前版本留下的配置，不再用作新版任务的完成条件。
每门课程使用网站本身的计时逻辑，文章完成后通过网站内部导航明确返回当前任务首页，触发页面保存流程。
视频通过网站播放器正常播放，并等待网站确认保存；若浏览器阻止播放，请在网页点击播放。
出现“是否继续”的课程提示时，程序通过对应的“确定”按钮继续。
程序不再每隔 285 秒整页刷新；旧刷新逻辑会重新进入原始课程并可能丢失最后一段进度。
学习页面时间不增加、网站拒绝保存或页面结构改变时，程序会停止并显示具体问题。
网站汇总时长可能在课程结束后延迟约 5 分钟更新，以学校网站记录为准。
Ctrl+C 可停止。程序会尝试通过网站内部导航保存进度；若网页异常，请在保留的浏览器中检查记录。

本机环境
独立 Windows Python 环境：.venv
依赖：DrissionPage 4.1.1.4
课程地址、浏览器路径、浏览器端口在 config.json 中配置。
浏览器登录资料保存在 .browser_data 中。
如果迁移到其他电脑，需要重新创建环境：
  python -m venv .venv
  .venv\Scripts\python.exe -m pip install -r requirements.txt

主要修改
site_adapter.py：新版表格、自动翻页、必学/选学要求、文章和视频详情、保存响应检查。
auto_expriment.py：按课程实际进度处理，检查卡住和上传失败，支持 --check / --verify。
get_name.py：自动收集全部未学课程，不再只读取第一页，也不再作为运行的前置依赖。
start.py / start.cmd：Windows 启动及检查菜单。
.local_backups：本次修改前的本地脚本备份。

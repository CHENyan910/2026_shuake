# auto_expriment
自动刷USTC实验室安全教育视频以及自动考试

## 本地新版网站适配（2026-10-16）

本地版本已针对任务 `https://sysaq.ustc.edu.cn/lab-study-front/examTask/22` 的表格布局修改。双击 `start.cmd`，选择 1 登录，然后选择 3 开始；选择 5 可先检查全部课程和网站要求。

程序自动翻页读取全部未学条目，从表格中的“去学习”按钮进入课程。完成条件分别读取网站显示的必学、选学时长；不再使用旧脚本的单一小时数。文章和安全视频均通过网站页面正常计时、保存，遇到停滞或保存失败会报告错误。原有的定时整页刷新逻辑已移除。

详细操作见 `LOCAL_SETUP.txt`。离线检查：`python -m unittest -v test_site_adapter`。本次修改前的脚本备份保存在 `.local_backups`。下面是上游仓库原有说明，安装后的启动顺序以本节为准。

## 题库整理与模拟验证（2026-10-19）

项目浏览器登录后，可在启动菜单选择 8 整理普通练习题库，选择 9 生成本地复习文件。首次使用或网站题量变化时，先运行 `.venv\Scripts\python.exe -X utf8 inspect_exam.py --catalog` 更新目录。

双击 `start.cmd`，先选择 1 登录，再选择 **10 自动模拟考试**，程序依次处理模拟说明、排队、组卷、答题、服务器保存核对、等待最短交卷时间、交卷和查分。已有未完成的本任务模拟试卷时会继续原试卷；没有未完成试卷时会开始一次新模拟。选择 **11 查看最近模拟成绩** 只查询已有成绩。修改启动菜单后，需要关闭旧菜单窗口并重新双击 `start.cmd`。

`practice_bank.py collect` 从网站普通练习逐页收集题目，通过练习作答读取网站反馈的标准答案，会产生练习及错题记录。每页独立保存，完成后核对网站题号集合与分类总数；再次运行会跳过已完成分类。它不操作考试页面，也不调用外部模型服务。

结果保存在 `exam_prep/`：`题库复习.html` 可本地搜索、筛选与查看答案，`题库汇总.csv` 可用 Excel 打开，`question_bank.json` 保留完整题目及网站反馈，`validation.json` 记录完整性和答案映射检查。网站仅提供少量题目的解析，其他题目明确标为未提供解析。复习备注保存在 `review_notes.json`。目录包含本账号的练习和模拟记录，已从 Git 中排除。

`mock_exam.py` 的模拟验证先核对全部题库，再从任务首页的“模拟考试”入口进入。`fill` 通过网页选项填写答案，并重新读取服务器核对保存结果；`submit` 等待网页允许交卷后才使用正常交卷确认框。每次作答和交卷前都向网站确认当前记录为模拟考试；答案按题干和选项内容匹配，未经核对的冲突或未覆盖题目会停止。工具不会修改计时器或交卷限制。

命令行也可使用 `mock_exam.py run` 执行完整模拟流程，使用 `mock_exam.py recent` 查询最近模拟成绩。分步命令仍保留：`start` 打开模拟说明，`begin` 确认开始；如需排队，排队结束后运行 `enter`。试卷生成后运行 `fill`、`submit`。这些命令均使用项目的 `.venv\Scripts\python.exe -X utf8` 执行。模拟期间保留浏览器窗口。检查：`python -m unittest -v test_exam_bank test_mock_exam`。

本次已完整核对 11 类、3478 道题目及网站答案，包含 1852 道判断题、1624 道单选题、2 道多选题；26 道题有网站解析，6 道题附有原题重复选项或答案疑问备注。任务 36 的模拟试卷 100 道题均已通过服务器重新读取核对，遵守最短交卷时间后正常提交，个人中心公布成绩为 100.0 分。记录见 `exam_prep/mock_result.json`；出分可能晚于交卷，可使用 `mock_exam.py result --wait-result` 正常查询。9 项答案匹配检查通过。

菜单接入后共 16 项检查通过，覆盖答案映射、模拟排队及中断恢复、保存失败时停止、正式考试状态保护、成绩记录隔离和菜单路由。新增选项11已实际查询到已有的 100.0 分记录；此次菜单改动未额外开启模拟考试。

## 正式考试与已授权安全承诺

按用户在本次会话的明确授权，菜单 **12 自动正式考试** 会进入正式说明，正常勾选并确认已核对的《实验室安全承诺书》，完成排队、组卷、答题和交卷查分。承诺通过网站正常控件及接口确认，原文、内容摘要与服务器响应保存在 `exam_prep/formal_promise_confirmation.json`。如果网站更改承诺条款或改为扫码、手写签名，程序会停止，保留页面供处理。

正式考试逐题处理，每道题保存成功后等待至少 **15 秒**，再写下一题；第一题前、最后一题后没有额外的固定等待。中断恢复会跳过已正确保存的题，并在继续写入前保留15秒间隔。100道题的99个题间间隔合计24分45秒，另需正常加载及保存时间。剩余时长不足时会停止，程序不会缩短间隔或修改网站计时。模拟考试保留原来的处理节奏。

正式试卷使用独立的模式核对与 `formal_` 结果文件，按网站正式记录确认任务及试卷编号后才填写、核对保存。已有未完成记录时继续原记录；没有未完成记录时，菜单12会开始一次新的正式考试。命令行对应 `.venv\Scripts\python.exe -X utf8 formal_exam.py run --confirm-promise`；不带授权选项时仅处理已在网页进入的正式试卷。

正式试卷题号可能与普通练习不同。当前试卷20983对应题库15517与15881，两题题干和选项相同，网站反馈分别为冷水与热水。`answer_resolutions.json` 记录了按冷水处理的核对依据（[中南大学实验室安全资料](https://ccce.csu.edu.cn/info/1591/7436.htm)）及两个来源的原始答案。规则只有在题干、全部选项、来源题号和各自答案均一致时生效，并按当前选项内容重新映射。原题库反馈保持原值；这份资料核对不能确认正式试卷服务器对该题的判分答案。

可用 `.venv\Scripts\python.exe -X utf8 formal_exam.py diagnose` 只读当前已打开的正式试卷并离线核对，不导航、作答或交卷。填写前会导出完整试卷及匹配报告到 `exam_prep/formal_paper.json` 和 `formal_answer_plan.json`；即使存在未解决的冲突也会记录全部问题，并在写入任何答案之前停止。修复后再次选择菜单12，会继续网站现有的未完成试卷。

检查命令为 `python -m unittest -v test_exam_bank test_mock_exam test_formal_exam test_answer_pacing`，38项离线检查通过，覆盖承诺核对、排队衔接、模式与成绩隔离、保存后15秒再答下一题、中断恢复、冲突核对与选项重排、诊断时不作答及剩余时间不足时停止。本次冲突修复仅只读导出用户已打开的正式试卷并核对答案映射，未代为作答或交卷。
